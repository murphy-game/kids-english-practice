# Kids English Practice

Static React/Vite/TypeScript app for GitHub Pages.

## Current stage
- Reads published Google Sheet CSVs.
- Local fallback data if Google Sheet fails.
- Content Check page for counts, emoji suggestions, and missing images.
- Browser TTS helper with optional MP3 override.

## GitHub Pages
Repository: `kids-english-practice`
Settings > Pages > Source: GitHub Actions

This project uses HashRouter for reliable static hosting, so the content checker is at `#/content-check`.
